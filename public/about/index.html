About NextReset

NextReset answers one question for twelve games: when does it next reset, patch or change season, or when did it last? Each answer is a date or a time taken from the publisher (or, for GTA Online's weekly reset, computed from its fixed rule), shown with where it came from, how precise it is, and when it was last checked.

What you will find here

  • A page for each game with the latest value — verified from the publisher's own source and linked to it, or for GTA Online computed from its weekly rule and named as such — its precision (an exact time, or a date only), and when it was last checked.
  • The history the trackers have kept: earlier patches and releases, and scheduled ones where a publisher announces them, each linked to the publisher's own page where it has one.
  • One table for every game, side by side, in UTC and in your own time zone.
  • Your own list: star the games you follow to keep them at the top. It stays on your device; there is no account.

How sources are chosen

A source is used only if the publisher runs it: Riot's League of Legends patch schedule and its VALORANT patch notes on playvalorant.com; the update posts Valve, KRAFTON and EA publish on Steam; the version manifest Mojang's launcher uses; HoYoverse's in-game announcements; the Call of Duty patch notes page; the feed behind status.roblox.com; and Rockstar's Newswire. GTA Online's weekly reset is computed from its fixed Thursday 10:00 UTC rule, and its page says so.

Fan wikis, community trackers, leaks and unofficial APIs are not used, even where they are often right. When a publisher's own source cannot be read, the page says so instead of borrowing a date: Fortnite's season end is read from Epic's Battle Pass page, and while that page refuses our checks, as it has since April 2026, no Fortnite date is shown. A source that blocks automated requests is not worked around.

How values are checked

  • Each source is read by code written for it, from a structured feed wherever the publisher offers one, several times a day.
  • One source is read with the help of a language model: Riot's League of Legends patch schedule. A date the model reports is kept only if the text it came from appears word for word on Riot's page, and only if it falls within two years of the day it was read.
  • Precision is kept as the publisher gave it. A day announced without a time is shown as a day; a time is never added that the publisher did not state.
  • The site is rebuilt from these values, and a page whose value cannot be filled in is not published with a placeholder in its place.

When we do not know

  • If a publisher has not announced a date, the page says No official date announced.
  • If a source cannot be reached, the last verified value stays on the page, marked Stale, with the time it was last verified.
  • If there is no value we stand behind at all, the page says Data unavailable.
  • Pages that cannot currently answer their question well (Fortnite, Roblox and Red Dead Redemption 2) stay online but are kept out of search results. Their values still appear in the reset table.

Corrections

When a value or a sentence here turns out to be wrong, we fix what produced it, not just the page, and add an automated check so the same mistake cannot come back. Every correction is a public change in the project's repository. Recent ones:

  • October 2026: four trackers described a source they do not read, pages promised countdowns that do not run, and GTA Online's computed reset was labelled "verified". Corrected, with a test that ties each page's description to the source it actually reads (change #76).
  • 12 October 2026: three statements about how often PUBG and League of Legends patch disagreed with the site's own data. Corrected (change #73).
  • 12 October 2026: the Fortnite page described a countdown it no longer had after Epic's page began refusing our checks. Corrected (change #67).

Who runs NextReset

NextReset is an independent project. It is not affiliated with, endorsed by or sponsored by any game publisher, and all trademarks belong to their owners. The site and the code that produces it are public: every change is a reviewed pull request in the nextreset repository on GitHub, so the history of every page and every source decision can be read there.

Advertising and privacy

The site is free and may show Google ads. No page is written or changed to suit an advertiser, and the arcade carries no ads at all. Nothing here needs a sign-in. The site uses Google Analytics and Google AdSense as the Privacy Policy describes, and asks for consent first where the law requires it.

Technical details

NextReset is open source and built with TypeScript, running on GitHub Actions for automation and served as static files. The frontend uses vanilla HTML, CSS, and JavaScript with no framework overhead. Most sources are read with plain HTTP requests; a few publisher pages that only render in a browser are read with a headless browser.

Contact

To report a wrong value or sentence, suggest a better source, or ask for a game to be tracked, open an issue on our GitHub repository.
