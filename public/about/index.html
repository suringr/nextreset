About NextReset

NextReset is a free website that tracks official game resets, updates, and patch releases for popular video games. Our mission is simple: give gamers accurate, honest information about when their games change — sourced directly from game publishers, with zero guesswork.

Why We Built This

If you've ever searched "when does Fortnite season end" or "GTA Online weekly reset time," you've probably landed on pages full of speculation, outdated information, or clickbait. We got tired of that. NextReset was built to be the opposite — a clean, fast site that shows you verified data from official sources and nothing else.

How It Works

The checks run on an automated schedule. The code that reads each source, and every page, is changed through reviewed pull requests in a public repository:

  • Several times a day, our system checks official game publisher websites, APIs, and news feeds for the latest dates and status information.
  • Data is extracted by code written for each source, from a structured feed wherever the publisher offers one. One source, Riot's League of Legends patch schedule, is read with the help of a language model; a date it reports is kept only if the text it came from appears word for word on Riot's page.
  • Dates are validated with sanity checks — we reject anything that looks like a parsing error or falls outside a reasonable range.
  • Results are published as static pages. Where a publisher gives an exact time, your browser turns it into a countdown; where it gives only a day, the page shows the day.
  • If a source fails, we preserve the last known good data rather than showing errors. You'll see a "Stale" indicator when this happens.

What We Track

We track 12 games covering battle royales, MOBAs, tactical shooters, sandbox games, and sports titles. Each game has a page with the latest value — verified from its official source, or for GTA Online's weekly reset computed from its fixed rule — and where it came from, how precise it is, and when it was last checked.

Our sources are the publishers' own: Riot's League of Legends patch schedule and its VALORANT patch notes on playvalorant.com; the update posts Valve, KRAFTON and EA publish on Steam; the version manifest Mojang's launcher uses; HoYoverse's in-game announcements; the Call of Duty patch notes page; the feed behind status.roblox.com; and Rockstar's Newswire. GTA Online's weekly reset is computed from its fixed Thursday 10:00 UTC rule. Fortnite's season end is read from Epic's Battle Pass page; while that page refuses our checks, as it has since April 2026, no Fortnite date is shown.

Our Principles

  • Official sources only — We never rely on leaks, rumors, or community speculation.
  • Honest data — If we don't have a date, we say so. We never fabricate or predict dates.
  • Transparency — Every tracker shows its source, confidence level, and last update time.
  • Corrections — When a value or a sentence here turns out to be wrong, we fix what produced it, not just the page, and add a check so it cannot come back.
  • No accounts — Nothing here needs a sign-in. The site uses Google Analytics and Google AdSense as the Privacy Policy describes, and asks for consent first where the law requires it.

Technical Details

NextReset is open source and built with TypeScript, running on GitHub Actions for automation and served as static files. The frontend uses vanilla HTML, CSS, and JavaScript with no framework overhead — resulting in near-instant page loads. Most sources are read with plain HTTP requests; a few publisher pages that only render in a browser are read with a headless browser.

Contact

NextReset is a passion project. If you have suggestions, notice incorrect data, or want to request a new game tracker, feel free to open an issue on our GitHub repository.
